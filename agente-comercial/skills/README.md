# Skills

As skills serão instruções modulares para tarefas específicas do Analista Comercial.

Skills planejadas:
- pesquisa e identificação de empresas;
- verificação de presença digital e titularidade de sites;
- avaliação PC, OD, QC, CE e prioridade;
- preparação de abordagem comercial personalizada;
- revisão de evidências e controle de qualidade.

Cada skill deverá definir entradas, procedimento, fontes aceitas, saídas estruturadas, critérios de bloqueio e exemplos de teste. Nenhuma skill poderá autorizar envio automático de mensagens.
