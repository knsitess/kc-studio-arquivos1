# Testes

Os testes deverão validar, no mínimo:
- ausência de leads fictícios;
- exigência de fonte e data para fatos;
- deduplicação da mesma tríade de evidência;
- exclusividade S2/S3;
- bloqueio de abordagem em Dados Insuficientes;
- cálculo PC, OD, QC, CE e prioridade;
- ausência de envio de mensagens sem aprovação humana;
- tratamento de fontes bloqueadas, snippets e candidatos pendentes.

Os três casos documentados em metodologia/metodologia-v2.5.md serão usados como referências de regressão, respeitando os limites de evidência disponíveis.
