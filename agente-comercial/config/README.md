# Configuração

Manter aqui apenas exemplos de configuração não sensíveis.

- Não armazenar chaves de API ou tokens no Git.
- Não incluir dados pessoais ou contatos de leads em arquivos de exemplo.
- As credenciais deverão ser fornecidas por variáveis de ambiente no ambiente de execução.
- Os nomes das variáveis serão definidos depois da escolha e validação do SDK e dos provedores.
